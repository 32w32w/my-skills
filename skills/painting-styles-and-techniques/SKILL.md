# Painting Styles and Techniques

用户要求创作一幅新画时，优先使用本技能，默认执行[完整绘画创作](#完整绘画创作)的九个阶段。仅提供题材的创作请求也从原作研究开始。用户明确只要查画、构思、点评已有画稿或核对局部修改时，按该次交付范围使用对应章节。奶蛙系列的角色约定只在该系列里使用。

| 用户想做什么 | 交付什么 | 按需查阅 |
| --- | --- | --- |
| 从题材或参考创作完整的原创画作 | 验收后的成图及各阶段记录 | [完整绘画创作](#完整绘画创作)、[《大侠买葱归来》完整案例](examples/scallion-swordsman.md) |
| 找到原作或分清版本 | 指向具体实物的馆藏记录，说明与同名作品、摹本、分段或印本的关系 | [馆藏索引](references/collections.md) |
| 看懂一幅画或比较画派 | 指到具体部位的观察、它的画面作用、能采用的画法及适用范围 | [四个技法示范](references/techniques.md) |
| 借一种画法创作新作品 | 一份可据以起稿的构思，写明要发生的事、取景、动作与观看顺序 | [《闭馆以后》构思示例](examples/after-hours.md) |
| 判断已有作品能否定稿 | 沿用原版评画页、独立评审意见与定稿取舍 | [正式作品评审](#正式作品评审) |
| 点评已有画稿或核对一处修改 | 指出具体位置、修改动作和复看的依据 | [单幅点评与局部验收](#单幅点评与局部验收) |

## 完整绘画创作

按表中顺序完成各阶段。上一阶段的成果达到放行条件后再进入下一阶段。检查发现问题时，修正对应成果，再复核受影响的后续阶段。阶段条件用于检查成果，用户要求分段审阅时按其约定停留。

| 阶段 | 交付成果 | 进入下一阶段的条件 |
| --- | --- | --- |
| 1. 原作研究 | 选定原作或馆藏版本的记录，含可复查的来源、所见图像或文字范围及相关观察 | 来源及版本可追溯，现有资料足以支撑拟提炼的画法 |
| 2. 技法提炼 | 可定位的画面依据、画法对观看的作用，以及向新题材的移用方案 | 每项拟用画法都有依据，并说明在这幅新画里解决什么问题 |
| 3. 原创艺术构思 | 独立构思稿，写明核心瞬间、画幅、构图、人物动作、视觉重心和观看顺序 | 六项彼此一致，画面关系具体到足以起稿。无人物题材明确这一点，写清承担叙事或动势的画面元素 |
| 4. 独立提示词工程 | 根据已完成构思另写的完整提示词 | 提示词把构思写成所选工具可执行的画面要求，已经具备逐项核对的条件 |
| 5. 生成前检查 | 构思要点、提示词对应内容和核对结果，以及修正后的提示词 | 六项构思要点和本次委托中的关键约束均已落实，冲突和遗漏已修正，所选工具及所需输入可用 |
| 6. 初稿生成 | 默认用 `image_gen.imagegen` 生成。可打开的初稿、采用的提示词或对应绘制参数，以及供检查的全幅和焦点局部 | 初稿的大形、明暗和主要动作或叙事关系已清楚到可以评审 |
| 7. 专业评审 | 初稿评画页和第一轮评审记录，含具体位置、画面现象、观看影响和优先修改项 | 优先问题有实际画面依据，修改方向和复验标准均已写明 |
| 8. 定向修改 | 默认用 `image_gen.imagegen` 编辑。修订稿、前后对照，以及逐项的“问题、改动、结果”记录 | 同位置、同尺度的对照显示优先问题得到解决，全幅仍符合构图、观看顺序和角色辨识度等关键要求 |
| 9. 定稿验收 | 最终尺寸的成图、交稿前评审和验收记录 | 按下文的交稿前评审复核全幅和焦点局部，作品达到已定的交付要求后收稿。发现影响交付的问题时回到相应阶段 |

技能、工具、素材或评审依赖缺失时，说清缺项、受影响的阶段和已经完成的成果。关键依赖无法补足时，该阶段记为受阻。可按原版细则补做自评并据此定位问题，独立评审仍记为待完成。完成情况以实际产出和检查记录为准。

## 查原作

从题名、别名、作者原文名、媒材或用户给的图像线索开始。用联合目录发现线索，再追到收藏方、原址管理机构或它们提供的藏品记录。只有展览网页时，注明主办方、出借方与网页性质。题名里有“传”“摹”“仿”时，沿用馆方归属。壁画可用所在建筑和具体墙面定位，版画要指到所讨论的那件印本。

让读者能复查同一件物品。给出作品名、作者或归属、年代、媒材、收藏方、馆藏号（如有）及直达链接。数据库页面编号和馆藏号按页面各自的名称记录。查到文字而图像受限时，交付现有记录，写明能看到的范围。需要下载、转载或选用原图时，再按该件和具体图档的使用说明记录出处、署名与许可。

## 从原作提炼画法

看一幅具体作品时，先在画面上选一个可定位的关系，例如“天平两侧的细线正好落在一片素墙前”。接着说明这怎样影响观看，最后给出能移用到新题材的一笔。写明观察来自实际看过的全图、局部还是馆方文字。只有文字时，把判断归给文字来源。

讨论画家时比较几件独立作品，讨论画派时把不同画家放进比较。记录重复出现的处理，再指出一个差异或只在某幅画成立的细节。一个手卷的两段、一个版画设计的不同印本，各自适合研究观看次序和印本差异。归纳风格时另选独立作品。

选择与媒材相称的问题。群像先看人物如何彼此回应，手卷看逐段展开的疏密，木版画看轮廓、色面和套印位置。对于颜料成分、底稿、罩染次序或某一处磨损的成因，引用馆方技术研究或修复记录；资料只支持视觉现象时，写下能看见的边缘、颜色或痕迹。

## 原创艺术构思

从这幅画独有的一刻写起。谁在做什么，谁发现了这件事，哪一处细节让观众也能发现？据此选择一两种有出处的画法。交代画幅、观众先看到什么、随后发现什么，以及取景、手势、光和背景怎样配合。换掉参考作品里的服饰和道具后，所借的画法仍应说得清。

按本次委托的用途选画幅。有指定比例或尺寸时按本次要求处理。用户明确要做壁纸时，依据目标设备的屏幕比例和裁切构图。自由创作时，让主体、动作和留白决定比例。示例里的尺寸只用于对应作品。

改编指定名作时，先辨认用户珍视的构图关系、人物互动或表情，再写明这次想加入的叙事和画面选择。用户有角色定稿时，按正面、侧面与遮挡关系读脸，保留辨识度，给视线与动作留下表达空间。

## 独立提示词工程

构思稿完成后，另写一份用于出图的提示词。把核心瞬间落实为可见动作，把画幅和构图落实为取景、主体位置和空间关系，再写明用光、边缘或色彩怎样建立视觉重心、引导观看顺序。按需要写入角色参考、画材和约束。画家名、画派名或风格形容词只能补充具体画面指令。

## 生成前检查

另作一份核对记录。逐项抄出关键构思要求，找出提示词中负责落实它的语句，并检查这些语句是否相互冲突、是否遗漏约束。例如核对指定的横幅、人物的朝向和遮挡、主光方向，以及次要物件的对比度是否会盖过视觉重心。修改提示词后复查对应项，再按最终版本起稿。

## 初稿生成

完整原创绘画默认使用 `image_gen.imagegen`，采用第五阶段已通过检查的最终提示词。调用前查看当前会话公开的实际工具接口、参数结构和能力。根据创作需要传入角色、构图、笔墨风格等参考图，在提示词中说明每张图的用途。只使用接口实际提供的参数。保存原始生成结果，另存新版本以保全已有稿件。

用户明确要求程序化绘画时，使用本地 `$painting`（`claude-painting-skill`）的 Dry 或 Oil，把已核对的画面要求落实为构图、明暗和绘制参数。Dry 和 Oil 也可用于程序化笔触实验、特定绘制参数研究、评画页、明暗分析和辅助检查。

## 定向修改

默认使用 `image_gen.imagegen` 的图像编辑能力。以通过第七阶段评审的初稿为起点，后续各轮沿用已通过复核的修订稿，按评审意见逐项修改。优先编辑局部，明确修改区与保护区。调用前核对实际接口，按其支持的方式传入底图及所需参考图，使用实际支持的蒙版或局部编辑能力。若接口缺少所需的范围控制，如实说明限制。需要严格保留原始像素时，可将生成的局部补丁用蒙版合回基准稿。

每轮独立保存原始工具输出与本轮修订稿。用同位置、同尺度的前后对照复核局部及全幅，逐像素检查实际改动范围。只有经实际比对确认的保护区才可记为像素级保留。将发现的越界改动列入复核，修正并重验后再放行。

## 第六、八阶段的工具异常与记录

`image_gen.imagegen` 不可用、调用失败、缺少必要权限或无法满足必需的输入或编辑能力时，报告受阻阶段与具体原因，保留已完成的成果，等待用户决定下一步。改用 Dry 或 Oil 须由用户决定。程序化绘画按实际绘制方式记录。

在创作记录中保存实际调用的工具、提示词、参考图及逐图用途、原始输出文件与保存路径。第八阶段另记基准版本、每轮修订稿、修改前后对照和像素核查与验收结果。模型 ID 或版本只在工具实际提供时按原值记录。

## 正式作品评审

正式作品直接采用 `$painting` 的原版评审流程。先读已安装的 `painting` 技能目录下的 `references/critique.md`，沿用这幅作品已有的评画页和评审记录。使用其他工具出图时，也可在该技能的油画环境中用 `python -m atelier.studio review` 为现有 PNG 制作评画页，指定焦点供原尺寸查看。

完整创作默认有两轮独立评审。每轮给一位未参与创作的评审看简短的构思摘要和评画页，按原版七项标准打分，指出画面依据、最多三项优先修改和一处值得保留的特点。把本次委托的要求写进同一份摘要，例如平板上希望先看到什么、角色的眼神该落向哪里，或手卷展开时哪一段应当留出停顿。

1. **大形成立后。** 在目标尺寸上对照构图计划、全幅、明暗缩图和焦点局部。检查相邻物件的遮挡、投影和所在平面，尤其是边缘相贴的地方。比如画框靠窗时，沿着窗洞的转角看画框是否完整地挂在同一面墙上。趁构图和光影还能调整，先修最影响读画的问题。
2. **交稿前。** 用最终尺寸再评全幅与焦点的 1∶1 局部，复看调整过的边缘和遮挡。另请第一次看画的人只看图，用一句话说自己看见了什么，隐去标题和构思提示。比如评《闭馆以后》时，可以从读者自己的描述判断他是否发现了量面包的动作。给用户挑草图时，每个候选也做一次这样的无标题读图。

两版难选时，在当轮用 `python -m atelier.studio compare` 生成同尺寸、相同局部的匿名对照，由同一位评审看两版，选定后再揭晓版本。每次修改后自查并记录“问题、改动、结果”。第二轮后若评分仍在上升，且首要问题确实能修，再考虑第三轮。目标已达到、改进停滞或遇到画材工具的限制时，复看最终图并记下取舍。

用户只要求验收已有成图时，从定稿环节开始。独立评审不可用时，按原版细则自评，注明评审依赖和实际完成情况。

## 单幅点评与局部验收

用户只问一张画哪里值得改，就看实际画面并交评语。按用途看全幅，找出视线先落在哪里，再看最影响画意的局部。版画回到彩色检查轮廓和色块，长手卷沿展开方向读。

只修一处时，用同位置、同尺寸的前后图验收。例如删除第三只奶蛙脸上的多余嘴线，要同时能指出消失的是哪一笔、保住的是哪一条笑线。最后回到全图看神情和动作是否连贯。
